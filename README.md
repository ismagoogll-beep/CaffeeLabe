# ☕ Coffee House — сайт кофейни

Одностраничный лендинг кофейни на чистом HTML + CSS + немного JS.  
Тёмная тема, золотисто-кофейные акценты, hover-анимации на `transform`, форма брони столика с отправкой заявки прямо в WhatsApp.

Никаких фреймворков, сборщиков и npm — открыл файл и всё работает.

## Структура проекта

```
coffee-house/
├── index.html    # разметка + скрипт отправки в WhatsApp
├── style.css     # все стили и анимации
└── README.md
```

## Как запустить

1. Скачай/склонируй проект.
2. Открой `index.html` двойным кликом в браузере — сервер не нужен.
3. Если хочешь по-нормальному, подними локальный сервер:
   - VS Code → расширение **Live Server** → кнопка «Go Live»
   - или в терминале: `python -m http.server 8000` → открой `http://localhost:8000`

Второй вариант лучше: при `file://` браузер иногда режет открытие новых вкладок (`window.open`).

| Секция | id | Что там |
|---|---|---|
| Шапка | — | фиксированное меню с blur-фоном, ссылки-якоря |
| Главный экран | `#home` | заголовок с градиентным текстом + кнопка «Записаться» |

Навигация работает через якоря + `scroll-behavior: smooth` в CSS. Кнопка «Записаться» скроллит к форме через `scrollIntoView`.

## Форма и WhatsApp — как это работает

Скрипт висит на `submit` формы `#bookingForm`:

1. `e.preventDefault()` — отменяет обычную отправку, страница не перезагружается.
2. Собирает значения полей: `name`, `phone`, `service`, `date`.
3. Кодирует их через `encodeURIComponent`, чтобы пробелы, кириллица и спецсимволы не сломали ссылку.
4. Склеивает текст сообщения (`%0A` — это перенос строки).
5. Открывает `https://wa.me/<номер>?text=<сообщение>` в новой вкладке.

Дальше человек просто жмёт «Отправить» в WhatsApp — и заявка улетает тебе в личку. Выглядит так:

```
Новая запись!
Имя: Иван
Телефон: +7 900 000-00-00
Услуга: Столик в кафе
Дата: 2026-11-25
```

### Поменять номер на свой

В `index.html`, в самом низу, в блоке `<script>`:

```js
var phoneNumber = '79634161424'; // код страны + номер, БЕЗ +, пробелов и скобок
```

Формат строго такой: `79634161424`, а не `+7 (963) 416-14-24`. Иначе ссылка не откроется.

### Поменять список услуг

Правишь `<option>` внутри `<select id="service">`:

```html
<option value="Столик в кафе">Столик в кафе</option>
```

`value` — то, что придёт в сообщении. Текст между тегами — то, что видит клиент. Можно делать разными.

### Добавить новое поле в форму

1. В HTML добавь инпут с уникальным `id`, например `<input type="time" id="time">`.
2. В скрипте забери его: `var time = document.getElementById('time').value;`
3. Долей в сообщение: `+ 'Время: ' + encodeURIComponent(time) + '%0A'`.

Важно: скрипт стоит **после** формы в конце `<body>`. Если перенесёшь его в `<head>`, `getElementById` вернёт `null` и всё сломается.

## Как поменять контент

**Цены и названия** — прямо в карточках `.menu-card` в `index.html`.

**Фотки** — атрибут `src` у `<img class="card-photo">`. Сейчас там внешние ссылки. Надёжнее скачать картинки в папку `img/` и прописать локально:

```html
<img class="card-photo" src="img/cappuccino.jpg" alt="Капучино">
```

Так сайт не зависит от чужого хостинга и грузится быстрее. Оптимальный размер — примерно 600×400, они всё равно режутся под `object-fit: cover`.

**Цвета** — вся палитра держится на трёх значениях, меняешь поиском по `style.css`:

| Цвет | Где используется |
|---|---|
| `#d4a574` | золотисто-кофейный акцент (заголовки, кнопки, рамки) |
| `#1a1a1a` | основной тёмный фон |
| `#252525` | фон чередующихся секций |

Хочешь светлую тему — меняй эти три + `color: #f5f5f5` у `body`.

## Анимации

Все эффекты на CSS, без библиотек:

- `.menu-card:hover` → `translateY(-10px) rotate(2deg)` — карточка приподнимается и чуть наклоняется
- `.card-photo` → `scale(1.05)` при наведении на карточку
- `.card-icon` / `.price` → увеличение и поворот
- `.nav a::after` → подчёркивание выезжает через `width: 0 → 100%`
- `.hero-content` → появление через `@keyframes fadeInUp`
- поля формы → `scale(1.02)` при фокусе

Скорость везде `transition: 0.3s ease` — хочешь плавнее, ставь `0.5s`.

## Что стоит доделать перед публикацией

- **Мобильная версия.** Медиазапросов пока нет: на телефоне шапка с `padding: 20px 50px` и заголовок `64px` будут вылезать. Добавь в конец `style.css` блок `@media (max-width: 768px)` с уменьшенными отступами и шрифтами.
- **Проверка телефона.** Сейчас `type="tel"` принимает любой текст. Добавь `pattern="[0-9+()\-\s]{10,18}"` на инпут.
- **Дата в прошлом.** Через `min` у `<input type="date">` можно запретить прошедшие дни.
- **Блокировщики попапов.** `window.open` иногда режется. Запасной вариант — `window.location.href = 'https://wa.me/...'`.
- **WhatsApp Desktop.** Ссылка `wa.me` открывается в браузере/приложении — на компе без WhatsApp Web клиент увидит заглушку. Это нормально, основная аудитория — мобилки.

## Деплой

Проект статический, подойдёт любой бесплатный хостинг:

- **GitHub Pages** — запушь репу → Settings → Pages → ветка `main`, папка `/root`
- **Netlify / Vercel** — просто перетащи папку с файлами в окно браузера
- **Обычный хостинг** — залей `index.html`, `style.css` и `img/` по FTP в корень сайта

Ничего собирать не надо, файлы уже готовые.

## Браузеры

Работает во всех современных: Chrome, Firefox, Safari, Edge.  
`backdrop-filter` (blur в шапке) в старых браузерах может не поддерживаться — там просто будет сплошной фон, не критично.
